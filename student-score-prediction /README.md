
# Student Score Prediction Using Machine Learning

## Project Overview
This project analyzes student performance data and predicts exam scores using linear regression.

## Objectives
- Analyze student performance data
- Explore correlations between study hours and exam scores
- Visualize student performance
- Build a machine learning prediction model
- Evaluate model performance

## Dataset
Synthetic dataset containing 10 students.

Features:
- Study hours
- Attendance rate
- Assignment score
- Exam score

## Technologies
- Python
- pandas
- matplotlib
- scikit-learn

## Machine Learning Model
Algorithm: Linear Regression

Input: Study hours

Target: Exam score

## Results
- Predicted score for 7.5 study hours: 78.55
- Mean Absolute Error (MAE): 0.93
- R-squared (R2): 0.9929

Evaluation was performed on the training data.
Results do not represent performance on unseen data.
