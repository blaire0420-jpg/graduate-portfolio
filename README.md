# Graduate Data Analysis Portfolio

This repository contains data analysis projects developed as preparation for graduate study in data science and related fields.

## Projects

### 1. Educational Environment Analysis of High Schools in Gyeonggi-do

An exploratory data analysis project using public school data from South Korea's School Information Disclosure System (학교알리미).

The project examines:

- Regional differences in students per teacher
- Regional differences in average class size
- Differences between public and private high schools
- Correlation between class size and students per teacher

**Key result:** Class size and students per teacher showed a strong positive correlation (r ≈ 0.96).

[View Project](gyeonggi-school-environment-analysis/)

## Tools

- Python
- pandas
- matplotlib


### 2. Student Score Prediction Using Machine Learning

This project analyzes student performance data and predicts exam scores using linear regression.

**Key Features:**
- Student performance data analysis
- Correlation analysis
- Data visualization
- Linear regression model
- Model evaluation using MAE and R-squared

**Key Results:**
- Predicted exam score for 7.5 study hours: 78.55
- MAE: 0.93
- R-squared: 0.9929

*Note: Results are based on synthetic training data.*

[View Project](student-score-prediction/)
