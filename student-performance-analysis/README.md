# Student Performance Analysis

## Project Overview
This project explores the relationship between study hours, attendance, sleep hours, and student scores using Python.

## Tools
- Python
- pandas
- matplotlib

## Dataset
A small sample dataset created for learning and practice.

## Analysis
- Created a student dataset
- Calculated descriptive statistics
- Analyzed correlations between variables
- Visualized the correlation matrix using a heatmap
- Exported the dataset and correlation matrix to CSV files

## Key Findings
- Study hours showed a strong positive correlation with scores.
- Attendance also showed a strong positive correlation with scores.
- Sleep hours showed a moderately strong positive correlation with scores.

## Limitations
The dataset contains only 10 simulated observations. These results are for practice and should not be generalized to real students.

## Files
- `analysis.py`: Python analysis script
- `student_data.csv`: Sample student dataset
- `correlation_matrix.csv`: Correlation matrix
- `correlation_heatmap.png`: Correlation heatmap
