# School Environment Regression Analysis

## Project Overview
This project uses linear regression to explore the relationship between study hours and average academic scores.

## Objectives
- Build a linear regression model using Python
- Calculate regression coefficients and the intercept
- Evaluate model performance using R-squared
- Compare actual scores with predicted scores
- Visualize the results with a scatter plot and regression line

## Tools
- Python
- pandas
- matplotlib
- scikit-learn

## Dataset
The project currently uses a small example dataset for practice. It is not real student or school data.

- Independent variable: Study hours
- Dependent variable: Average academic score

## Analysis
The model learns a linear relationship between study hours and average scores. It then generates predicted scores and evaluates how closely the regression line fits the example data.

## Output
- Regression coefficient
- Intercept
- R-squared score
- Actual vs. predicted score table
- `regression_analysis.png`
